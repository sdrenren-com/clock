Clock 双语言罗盘时钟
一款简洁美观的 html+原生js+css 双语言动态罗盘时钟网页项目，纯前端实现，界面流畅、轻量化，可直接部署使用。

✨ 项目简介
本项目是一个可视化罗盘时钟页面，支持双语言展示时间信息，动态轮转展示时分秒、日期，界面简约高级，适配电脑端浏览，无任何依赖，打开即可运行。

🎯 核心功能
- 动态罗盘时间轮转效果
- 双语时间文字展示
- 实时时分秒、日期自动更新
- 轻量化纯前端，零依赖、开箱即用
- 界面简洁美观，动态视觉效果流畅

🌐 在线演示
http://jl.sdrenren.com/clock.html

📁 项目结构
- clock.html：项目主页面，包含全部样式与逻辑

🚀 使用方式
1. 下载本项目全部源码
2. 直接使用浏览器打开 clock.html 即可运行
3. 可自行部署至服务器、静态网站平台

💡 自定义修改
可自由修改页面样式、配色、文字语言、动画速度等内容，代码结构清晰，易于二次开发与个性化调整。
